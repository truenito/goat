# My Notifications (`truenito.notifications`)

goat's notification service for the Omarchy shell: popups, do-not-disturb,
and history. It started as Omarchy's built-in `omarchy.notifications` plugin
(MIT), customized here.

`install.sh` links it into `~/.config/omarchy/plugins/`, and the saved shell
settings enable it and disable the built-in one, so edits here reload live.

Also published on its own, for people who want just the notifications, at
[truenito/omarchy-notifications](https://github.com/truenito/omarchy-notifications).
